# MeetSpace - ระบบจองห้องประชุม Enterprise
## (Meeting Room Booking System)

ระบบบริหารจัดการและจองห้องประชุมแบบครบวงจร พัฒนาด้วย Next.js 14+ (App Router), React 18, TypeScript, Tailwind CSS, Prisma ORM (SQLite) และ Server-Sent Events (SSE) สำหรับ Real-time Notifications

---

## 🌟 คุณสมบัติเด่นของระบบ (Core Features)

1. **ระบบจัดการและแสดงห้องประชุม (Meeting Rooms)**
   - แสดงสถานะห้องประชุมแบบ Real-time: 🟢 ว่าง (Available), 🔴 กำลังใช้งาน (Occupied), 🟡 จองแล้ว (Reserved), ⚫ ปิดปรับปรุง (Maintenance)
   - ตัวกรองอัจฉริยะ (Filter) ตามความจุ, สถานะ, อาคาร/ชั้น และอุปกรณ์อำนวยความสะดวก
   - ผู้ดูแลระบบ (Admin) สามารถเพิ่ม แก้ไข ลบห้องประชุม และกำหนดอุปกรณ์ประจำห้องได้

2. **ระบบตรวจสอบและป้องกันการจองชนกัน 100% (Zero Collision Booking Engine)**
   - ตรวจสอบช่วงเวลาซ้อนทับทันที: `(new_start < existing_end) && (new_end > existing_start)`
   - ป้องกันการจองห้องที่อยู่ระหว่างการปิดปรับปรุง (Maintenance Lockout)
   - ตรวจสอบความจุผู้เข้าร่วม (Capacity Enforcement)
   - **ระบบแนะนำอัตโนมัติ**: หากเวลาชน จะแนะนำห้องอื่นที่ว่างในเวลาเดียวกัน และช่วงเวลาว่างอื่นของห้องเดิมในวันเดียวกันทันที

3. **ปฏิทินการจองอัจฉริยะ (Multi-View Interactive Calendar)**
   - รองรับมุมมอง: รายเดือน (Month), รายสัปดาห์ (Week), รายวัน (Day) และกำหนดการ (Agenda)
   - คลิกที่ Event เพื่อดูรายละเอียด, ผู้จัด, แผนก, วาระการประชุม และสั่งแก้ไขหรือยกเลิกการจองได้

4. **แดชบอร์ดผู้บริหาร (Executive Dashboard & Visual Charts)**
   - สรุปสถิติแบบ Card: ห้องทั้งหมด, ห้องว่าง, กำลังใช้งาน, การจองวันนี้/สัปดาห์/เดือน, รออนุมัติ, และอัตราการใช้งานห้อง (Utilization Rate %)
   - กราฟแท่งแสดงสถิติการจองย้อนหลัง 7 วัน และ Donut Chart แสดงสัดส่วนการใช้ห้องแต่ละห้อง
   - แสดงการประชุมที่กำลังจะเริ่มถัดไป (Upcoming Meetings) และประวัติล่าสุด

5. **ระบบการแจ้งเตือนแบบ Real-Time (Server-Sent Events & In-App Bell)**
   - แจ้งเตือนทันทีเมื่อมีการจองใหม่, การอนุมัติ, การปฏิเสธคำขอ พร้อมป้ายตัวเลขนับจำนวนที่ยังไม่ได้อ่าน
   - แสดง Toast Notification ป๊อปอัปมุมจอเมื่อเกิดเหตุการณ์ในระบบ

6. **ระบบรายงานและส่งออกข้อมูล (Reports & Export CSV/PDF)**
   - ตัวกรองช่วงเวลา: วันนี้, สัปดาห์นี้, เดือนนี้, ปีนี้ และ Custom Date Range
   - สรุปจำนวนชั่วโมงที่ใช้งานจริง, ห้องที่ถูกใช้มากที่สุด/น้อยที่สุด, สถิติการยกเลิก
   - ส่งออกข้อมูลเป็นไฟล์ Excel / CSV (รองรับภาษาไทย UTF-8 BOM) และหน้าพิมพ์สรุปสำหรับบันทึกเป็น PDF

7. **ระบบบริหารผู้ใช้งานและบันทึกประวัติความปลอดภัย (User Management & Audit Logs)**
   - จัดการผู้ใช้: เพิ่ม, แก้ไข, ระงับ/เปิดการใช้งาน (Enable/Disable), สลับ Role (User, Manager, Admin) และรีเซ็ตรหัสผ่าน
   - บันทึกประวัติกิจกรรม (Audit Trail) ทุกการกระทำลงในฐานข้อมูล

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Installation & Run)

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd meeting-room-system

# 2. ติดตั้งแพ็กเกจ
npm install

# 3. ซิงค์ฐานข้อมูล Prisma (SQLite)
npx prisma db push

# 4. นำเข้าข้อมูลเริ่มต้น (Seeder)
npm run db:seed

# 5. เริ่มต้นเซิร์ฟเวอร์
npm run dev
# หรือรัน production build
npm run build
npm start
```

เปิดเว็บเบราว์เซอร์ไปที่: **http://localhost:3000**
